# BEAMpdf

Turns a PDF into a PowerPoint or Keynote presentation: every page becomes a full-quality slide that looks exactly like the PDF. By [BEAM Events](https://beamevents.com).

This repository only holds the **installers and updates**.

## Download
Get the latest version from **[Releases](https://github.com/BEAMevents/BEAMpdf/releases/latest)**:

- **BEAMpdf-x.y.z-mac-arm64.dmg** (Mac, Apple Silicon).
- **BEAMpdf-Setup-x.y.z.exe** (Windows) installs BEAMpdf. **BEAMpdf-Portable-x.y.z.exe** runs without installing.

The Mac app is signed and notarized by Apple (from version 1.0.4), so it opens with a normal double-click. The Windows installer isn't code-signed yet, so SmartScreen may warn on first launch: click **More info → Run anyway**.

## Updates
Click the version number at the top of the window. Installed copies download new versions in the background and show **Update x.y.z ready**: click it, then **Install & restart**.

## Problems?
Use **Help → Send Diagnostics to BEAM…** (or the version number at the top). It sends BEAMpdf's log and a short status report to BEAM, never your PDFs.
